# LegionFanControl

联想拯救者（Legion）风扇控制工具，用于**平替「联想电脑管家」里的「降温除尘」功能** —— 从而可以卸载电脑管家，同时保留一键除尘的能力。

---

## 环境要求

| 项目 | 要求 | 备注 |
|---|---|---|
| 笔记本电脑 | 联想拯救者 Legion 机型 |  |
| 操作系统 | Windows 10 / 11 |  |
| JDK | **25** | 运行JVM JAR 版本程序时需要 |
| 权限 | **管理员权限** | 运行期必需，程序会自动申请 |

程序通过调用 `powershell.exe` 访问 WMI，无需安装任何第三方驱动或运行库。

## 功能特性

| 功能 | 状态 | 说明 |
|---|---|---|
| 一键「降温除尘」 | 可用 | 固件级风扇满速；约 **2 分钟**后自动交还 EC 自动控制 |
| 120 秒倒计时 | 可用 | 到期自动复位，无需人工干预 |
| 双风扇转速实时显示 | 可用 | 带方位标注（左 / CPU 侧、右 / GPU 侧；方位为推断） |
| CPU / GPU 温度实时显示 | 可用 | 现代机型走 CapabilityID 通路 |
| 智能风扇模式显示 | 可用 | 安静 / 均衡 / 性能 / 自定义 |
| 硬件状态校正 | 可用 | 固件自动复位或外部改动后，界面状态自动同步 |
| 管理员权限自动获取 | 可用 | 启动时若未提权，自动请求 UAC 以管理员身份重启自身 |
| 单风扇定向控制 | **不支持** | 固件接口层面不支持（见[已知限制](Docs/LimitationsAndRoadmap.md#1-满速除尘是全局开关不支持单风扇定向控制)） |
| 自定义转速曲线（v2） | 未实现 | 需逆向 `Fan_Set_Table` 二进制布局 |

## 快速开始

### 直接使用

三种方式**任选其一**，用的都是同一份源码与同一个版本号。按推荐程度排列：

#### 1. 原生镜像版（推荐）：双击 `Dist\LegionFanControl.exe`

单个**自包含** exe，**不需要 JDK** —— JavaFX 平台原生库已编进镜像。

| 项 | 说明 |
|---|---|
| 依赖 | 无（不需要 Java 运行时） |
| 控制台窗口 | **不会出现**：exe 以 GUI 子系统链接，双击与右键「以管理员身份运行」都只有界面，也没有一闪。需要看 `渲染诊断：…` 日志时，从命令行运行它（日志打在那个 cmd 窗口里），或加 `--console` / 把 `-Dlegion.console=true` 写进快捷方式的「目标」 |
| 管理员权限 | **需手动提权**：原生 exe 形态不支持启动时自提升（探不到 jar 路径），请右键「以管理员身份运行」（原因见下节） |

详见 [`Dist/README.md`](Dist/README.md)。

#### 2. JVM 版：双击 `Dist\Bootstrap.cmd`

需要 **JDK 25+** 且 `java` 在 `PATH`（见「环境要求」）。脚本已把运行所需的全部内容封装好：

| 脚本代劳的事项 | 说明 |
|---|---|
| JVM 参数 | 自动附加 `--enable-native-access=ALL-UNNAMED` |
| jar 路径 | 取与本脚本同目录的 `LegionFanControl.jar`，**不做版本号匹配** |
| 管理员权限 | 自动检测，不足时自动弹出 UAC 请求提权 |
| 环境检查 | jar 缺失、Java 不可用时给出明确提示 |

> **窗口行为**：正常启动后脚本**立即退出、窗口自动关闭**（不需要按任何键）；只有出错才停在窗口里。
> 代价是 `渲染诊断：…` 日志不再显示在窗口里 —— 需要日志时，请在**已提权的终端**里运行
> `Bootstrap.cmd --console`（已提权时不会再触发提权重启，参数不会丢），或直接用下面的「jar 模式」。

> `Dist/` 是**自包含文件夹**：整个目录拷贝到任意位置都能直接运行，不依赖源码工程。

#### 3. jar 模式：手动命令

在**管理员**终端中执行：

```bash
java --enable-native-access=ALL-UNNAMED -jar Dist/LegionFanControl.jar
```

> 原生包与 JVM 包的版本号相同、源码相同；出问题时可以互相对照（例如比对原生包与 JVM 版的渲染差异）。

### 关于管理员权限（重要）

> [!IMPORTANT]
> **必须以管理员身份运行**。联想 WMI 提供程序在非管理员上下文下会直接返回「拒绝访问」，转速与温度全部无法读取。
>
> 区别在于怎么拿到管理员权限： **`Bootstrap.cmd`（JVM 版）** 会在权限不足时自动弹出 UAC 请求提权，无需手动处理；**原生镜像版 exe** 不支持启动时自提升，需右键「以管理员身份运行」（或从已提权的终端启动）。
> 详细说明见 [`Dist/README.md`](Dist/README.md) 的「为什么必须管理员权限」。
